# 🔢 Sudoku Game & Solver (C Project)

This is a **console-based Sudoku game and solver** developed in **C** during Class 11.  
The project features a random puzzle generator, difficulty selection, colored output using basic C graphics, and a solver using a **backtracking algorithm**.

---

## 🎮 Features

- 🧩 Pre-solved Sudoku grids used to generate puzzles
- 🎚️ Difficulty levels: Easy, Medium, Hard
- 🎲 Randomized cell hiding to vary puzzles each time
- 🎨 Console-based UI using basic graphics and colors (e.g., Turbo C)
- ❌ Displays message if puzzle is unsolvable

---

## 🛠️ Tech Stack

- **C Programming**
- **graphics.h / conio.h** (for color output and layout)
- **Random number generation**
- **2D Arrays and Recursion**

---

## 📦 How to Run

1. Compile the program using a compiler that supports graphics (e.g., Turbo C or Dev C++):
   ```bash
   tcc sudoku.cpp
2. Run the executable
   ```bash
   ./sudoku

📝 Note: On modern systems, you may need DOSBox or an IDE that supports legacy C graphics.
