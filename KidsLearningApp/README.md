# Kids Learning App 📱🎨

A basic Android application developed using **Android Studio**, aimed at helping young children learn fundamental concepts in a fun and engaging way. This app presents multiple interactive learning categories such as:

- 🍎 Fruits
- 🥕 Vegetables
- 🌍 Country Flags
- 🔤 Alphabets (A-Z)
- 🔢 Numbers (0-9)
- 🎨 Colors

## 🛠️ Built With
- Java (Android)
- Android Studio
- XML (for UI design)

## 📦 Features
- Simple and colorful UI for kids
- Interactive categories with images and names
- Works offline
- Lightweight and fast

## 🏁 Project Status
- Fully functional and tested on real Android devices
- Originally published on Google Play Store (inactive account now closed)
